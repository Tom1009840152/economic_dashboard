## A1 执行记录与旧库部署顺序

- A1 已提供 `GET /api/analysis/cn/business-cycle/matrix` 与中国综合分析页入口，当前方法版本为 `1.0.0`。主分数使用五个固定 20% 基础权重板块；月度信号至少使用此前 24 个观测、季度信号至少使用此前 8 个观测，在最多 60 个月的单边窗口内计算稳健标准分。
- 工业增加值历史由国家统计局近期发布与东方财富传输镜像合并；M1-M2 只使用 `1.1.0` 及 2024-01 以后的可比口径；旧公式记录保留在版本库中，但不与现行口径拼接。接口分别报告输入到齐率、有效板块覆盖率和已知发布时间覆盖率，并在有效信号集合或归一化权重变化时禁止直接展示环比结论。
- 旧数据库中的 `CN_GDP` 曾把累计季度值记在 1/4/7/10 月。升级时必须先暂停后端调度器及其他写入者，部署迁移脚本但不要启动包含新版采集器的 Web 进程，然后在 `backend` 目录依次执行只读预检和带唯一备份文件的迁移：

  ```powershell
  .\.venv\Scripts\python.exe scripts\realign_cn_gdp_quarters.py
  .\.venv\Scripts\python.exe scripts\realign_cn_gdp_quarters.py --apply --backup ..\..\economic-dashboard-backups\cn-gdp-before-realign-YYYYMMDD-HHMMSS.json
  ```

  备份目录应放在 Git 仓库之外，避免真实数据库快照被误提交。

  迁移会在同一事务中把当前值及关联版本记录移动到 3/6/9/12 月。确认输出为 `applied` 或 `no_change`，且当前值和版本记录均只落在季度末月份后，才能启动新版后端和自动刷新。若目标季度末已存在记录，脚本会拒绝模糊合并；不得绕过检查，应先核对冲突来源。当前项目数据库已于 2026-09-13 完成该迁移。
