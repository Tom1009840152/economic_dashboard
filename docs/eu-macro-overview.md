# 欧元区宏观综合分析

入口：`GET /api/analysis/eu/overview`，页面为 `/country/eu/analysis`。

## 范围

- 本页分析欧元区，当前聚合口径为 EA21，不是欧盟 EU27。
- 总量可能遮蔽德国、法国、意大利、西班牙等成员国之间的周期、财政和融资分化。
- 不同序列的历史成员范围可能随欧元区扩员而变化；页面不把全部历史点描述成固定成员构成。

## 五个独立模块

1. 增长与景气：实际 GDP 同比、工业生产同比的连续三个月均值、ESI 水平及三个月方向。
2. 就业与劳动力：Eurostat EA21 失业率、就业率、参与率、劳动力闲置率及青年失业率。
3. 通胀环境：总体与核心 HICP；2% 是 ECB 的中期总体 HICP 目标，核心指标用于观察黏性。
4. ECB 货币政策：主要再融资操作利率、六个月变化及减核心 HICP 的事后实际利率代理。
5. 流动性与市场背景：ECB 总资产、EURO STOXX 50 和 EUR/CNY。该模块不是完整金融条件指数。

各模块按公开规则分别定性，不合成黑箱总分。每项指标保留自己的观察期，季度、月度、周度和日度数据不强行对齐到同一天。
顶部覆盖率把已知但尚未接入的主权收益率、信用利差、银行贷款和 M3 也计入分母，避免“已实现指标都有值”被误读为金融条件覆盖完整。

## 下行证据广度

页面等权检查六项可用证据：

- GDP 同比为负；
- 工业生产连续三个月均值为负；
- ESI 低于 100 且三个月继续下降；
- 失业率三个月上升至少 0.3 个百分点；
- 就业率较一年前下降；
- EURO STOXX 50 约三个月跌幅超过 10%。

只统计有值的信号。少于三项可用时不作判断；一项及以下为“有限”，两项为“增加”，三项及以上为“广泛”。这只是当前证据广度，不是衰退概率，也不替代事后的周期认定。

## 更新与降级

- 入库指标按各自上游发布节奏更新；Eurostat 就业数据通过独立接口补充，并使用六小时缓存。
- 就业补充请求在综合分析中最多等待五秒；超时后就业模块保持缺失，整页继续展示，缺失值不填零。
- Eurostat 单个可选序列暂时失败时，其余就业序列仍返回，并在警告中列明缺项。
- 核心序列尚缺完整 `release_date`、`available_at` 和历史版本，因此当前只能称最终修订快照，置信度最高为中等，不能用于伪实时回测。

## 重要限制

- 当前政策利率输入为 ECB 主要再融资利率，不是存款便利利率；事后实际利率只是方向性代理。
- 目前没有欧元区主权收益率、成员国利差、企业信用利差、银行贷款、M3、银行贷款调查、工资和服务通胀等关键输入。
- ECB 总资产变化不等同 M1/M2 或银行信贷，也不纯粹代表量化紧缩。
- EUR/CNY 是双边人民币交叉汇率，不是欧元名义有效汇率；只作外部背景，不参与金融条件状态判断。
