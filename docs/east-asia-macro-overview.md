# 日本与韩国宏观综合分析

## 定位

`GET /api/analysis/jp/overview` 与 `GET /api/analysis/kr/overview` 提供当前修订数据的透明快照。页面分开呈现增长、就业、通胀、金融背景与货币政策，不合成黑箱总分，也不输出未经回测的衰退概率。不同频率保留各自观察期，缺失和过期值不填零；月度3/6/12个月变化必须找到对应日历月，缺月时不以更早一行代替。

## 日本

- 增长使用工业生产近3个月同比均值与OECD CLI；季度GDP尚未接入，因此只能判断局部活动和领先方向。
- 就业使用15—64岁失业率、青年失业率、参与率和就业率；该年龄口径不覆盖日本重要的65岁以上劳动供给。
- 通胀同时展示总体CPI与OECD“剔除食品和能源”可比核心CPI。后者不同于日本国内通常所称的“剔除生鲜食品”核心口径。
- `JP_BOJ` 是OECD经FRED分发的24小时以内拆借/同业利率月均，不是日本银行最新会议的官方目标利率。方向规则使用6个月日历窗口；事后实际代理为该月均利率减可比核心CPI。
- 日本银行总资产只代表央行资产负债表背景；日经225进入市场检查，JPYCNY只作双边汇率背景。
- 下行证据设计为GDP、工业生产、CLI、失业率、就业率与日经225六项；当前GDP不可用时，`total_signals`只统计其余可用信号。

## 韩国

- 增长使用工业生产近3个月同比均值与OECD CLI；没有GDP时不写成GDP扩张或收缩。
- 就业额外关注青年失业率同比变化，避免总体低失业掩盖年龄分化。
- 当前只有OECD核心CPI，缺少总体CPI；韩国银行2%目标针对总体CPI，因此不直接以核心值判定目标达成。
- 韩国银行官方基准利率使用官网事件历史。最近变动生效日、官网明确的源端核验日与本地抓取时间分别记录；持平会议不会伪造一条新事件。近6个月和12个月变化以源端核验日为锚点，按日历时点的有效利率计算。
- 事后实际政策利率代理为官方基准利率减OECD可比核心CPI。由于韩国银行2%目标针对总体CPI，该值只用于方向判断，不等同完整的实际利率缺口。
- 外汇储备只代表外部缓冲，不是货币供应、韩国银行总资产或国内流动性。
- 当前六项下行检查是工业生产、CLI、总体失业、就业率、青年失业与KOSPI；两项触发为“证据增加”，三项及以上才为“广泛”。

## 可靠性边界

两国大部分历史回填点没有完整的 `release_date`、`available_at` 与观测级 `source_url`，且OECD/FRED序列可能修订。因此 `realtime_ready` 固定为 `false`。韩国银行事件表从官网页面严格解析并为每条事件保留官方来源链接；页面末尾若出现无标签、利率不变的当日延长点，只持久化为源端核验日，不写入调息历史，也不以本地抓取时间代替。就业抓取允许单条FRED序列失败时部分降级；失败项保持缺失并写入警告，只有六条源序列完整时才缓存聚合结果。
