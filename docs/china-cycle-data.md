# 中国经济周期数据层

## 时间与版本口径

`data_points` 保存每个观察期的当前值，现有看板继续从这里读取。`data_point_vintages`
是追加式版本表，只有数值或发布元数据发生变化时才新增一版。

- `date`：观察期，不是网页发布日期。
- `release_date`：统计发布日。
- `available_at`：可以进入实时判断的信息时点；能取得发布时间时精确到分钟。
- `retrieved_at`：本系统实际抓取并保存该版本的 UTC 时间。
- `version`：同一指标、同一观察期从 1 开始递增。
- `status`：`published` 为官方发布，`derived` 为可复算派生值，
  `historical_backfill` 为无法恢复原始发布时间的官方历史回填，
  `derived_backfill` 为基于最终历史值计算且不能进入严格伪实时回测的派生值，
  `mirror_backfill` 为第三方镜像历史回填，`backfilled` 为迁移前已有最终值。

伪实时回测必须使用 `available_at <= 回测时点` 的版本。没有 `available_at` 的历史回填值
不得进入严格的伪实时样本，但可以用于最终值模型训练和长期图表。

后端提供两种时点查询：单指标历史 `/api/as-of/indicators/{code}/history`，以及多指标
快照 `/api/as-of/snapshot`。默认严格模式排除发布时间未知的数据；只有显式关闭严格模式时，
才使用 `retrieved_at` 作为保守的首次可见时间。

## 当前已接入的周期输入

- 国家统计局：制造业和非制造业 PMI 分项、规上工业增加值、工业企业利润/收入/库存、房地产投资/销售/新开工/施工、名义 GDP。
- 人民银行：社融存量增速、社融口径人民币贷款余额增速、政府债券净融资。
- 财政部：一般公共预算支出、政府性基金预算支出、广义财政支出、新增地方专项债。
- 历史镜像：社融人民币贷款和企业债券分项、消费者信心/满意/预期、企业景气、70 城房价扩散指标。

所有周期输入的 `is_visible` 都为 false。它们不会自动变成国家页卡片，而是供后续综合
分析、周期识别和详情页使用。

## 派生公式

信用强度使用过去 12 个月新增社融除以最近可得的四季度滚动名义 GDP；标准信用脉冲
是信用强度较 12 个月前的百分点变化。财政支出强度仅在季度末计算，使用当年累计的
一般公共预算支出与政府性基金预算支出之和除以同期累计名义 GDP；财政脉冲代理是该
比率较上年同期的百分点变化。

上述公式和 M1-M2 剪刀差由 `derived_metrics` 唯一定义。派生观测将 `formula_version`
同时写入当前值表和版本表；当前版本为 `1.0.0`。同比差值按完整日历月或季度对齐，缺失
期间不会用“前 12 行/前 4 行”替代同月或同季度。

## 数据字典、质量门禁与刷新台账

- `/api/indicator-catalog` 输出全部147项指标的来源、频率、季调、度量类型、累计属性、模型方向、推荐变换、发布滞后、硬边界和口径备注。
- 写入前检查空数据、无效值、重复/未来日期、行数突降、单位突变、硬边界、发布元数据和消费者信心分项重复映射。
- `/api/refresh/status` 与 `/api/refresh/runs` 提供刷新总状态及逐指标行数、版本变化、耗时、错误和质量问题。

## D7：历史发布证据回填

国家统计局《中国采购经理指数运行情况》同一张原发布页同时提供制造业生产/就业、非制造业商务活动/就业及多个领先分项。归档采集只把标题对应的当月行标为 `published` 并使用该页面的实际发布时间；表内其余滚动历史行仍是 `historical_backfill`，不能借用当前页面时间。`CN_NMI` 的准确口径是“非制造业商务活动指数”，不是虚构的非制造业综合 PMI。

`CN_NMI` 的常规刷新继续保留原有长历史，再以最新官方发布页补充近期月份的真实发布时间；不能直接用约 13 个月的滚动发布表替换长序列，否则会触发行数坍塌门禁，新库也会失去历史基准。

工业增加值和社会消费品零售总额也从各观察月自己的国家统计局发布页解析。对“1—N 月”累计标题，只接受正文中独立陈述的第 N 月单月同比，不能把累计同比误作单月值。归档写入再做精确值核对：原发布值必须与已有当前快照完全一致才允许补充 `release_date`、`available_at` 和 `source_url`；归档模式不凭历史页新建当前观测。不一致说明其后发生过无法定位公开时间的修订，脚本只报告并跳过，不把旧值覆盖成最新值。页面只有发布日期而没有时分时，不推测午夜发布时间，`available_at` 保持未知。

2026-09-14 实际回填结果：

- `CN_NMI`：59 条官方发布证据，0 个值冲突；回测截止 2026-07 时有 58 条，且全部在固定决策截止前可用，范围 2021-09—2026-07。
- `CN_IP`：53 条官方发布证据，0 个值冲突；回测截止时 53 条发布时间已知、52 条在固定次月 20 日决策截止前可用。
- `CN_RETAIL`：50 条官方发布证据，0 个值冲突；回测截止时 50 条发布时间已知、49 条在固定决策截止前可用。
- 制造业和非制造业 PMI 分项原有 59 条同页证据，复跑为 0 个新增版本，说明回填幂等。
- 两个同步板块可在 2023-10—2026-07 连续 34 个月严格评分。D7 完成时的历史回放快照受成分可比性和确认规则约束，只有 5 个非连续阶段可比月，尚无正式决策可比月；这组 5/0 数字仅记录当时基线，不是当前 D9 回放结果。

归档命令从 `backend` 目录以模块方式执行。先预检，再去掉 `--check-only` 写入：

```powershell
.\.venv\Scripts\python.exe -m scripts.backfill_china_cycle --group activity --archive --archive-pages 70 --check-only
.\.venv\Scripts\python.exe -m scripts.backfill_china_cycle --group activity --archive --archive-pages 70
```

成功读取的官方详情页 HTML 缓存在 `backend/.cache/nbs-release`，便于限速续跑且不进入 Git；会变化的归档索引页每次重新读取。缓存只保存通过页面校验的正文，JavaScript 验证页不会作为证据。

## D9：旧分片、房地产与信用解析升级

国家统计局现行 `index.html` 至 `index_66.html` 只到 2021-09；旧资料并非继续使用 `index_67.html`，而是每 1000 条切换到 `index_1000*`、`index_2000*`。归档命令支持分片和相对页起点，小批量运行可避免触发官网验证并从失败页续跑：

```powershell
.\.venv\Scripts\python.exe -m scripts.backfill_china_cycle --group activity --archive --archive-shard 1000 --archive-start-page 0 --archive-pages 20 --check-only
.\.venv\Scripts\python.exe -m scripts.backfill_china_cycle --group activity --archive --archive-shard 1000 --archive-start-page 0 --archive-pages 20
```

2018 年以前，制造业 PMI 与非制造业商务活动是两篇独立发布稿；采集器同时识别“中国制造业采购经理指数”和“中国非制造业商务活动指数”，再按同一观察月合并。房地产采集兼容旧标题与“商品房/新建商品房”等标签变化，也能从迁移后的旧页面标题时间栏读取真实发布时间。相关历史证据只接受 HTTPS 官方 `stats.gov.cn` 页面。2026-09-15 完成此轮 D9 后：

- `CN_NMI`、PMI 生产、制造业 PMI 就业、非制造业 PMI 就业各有 125 个观察月发布时间已知且均在固定决策时点前可用，范围 2016-03—2026-08；
- `CN_IP` 有 114 个月发布时间已知、112 个月按时可用，范围 2016-02—2026-07；
- `CN_RETAIL` 有 100 个月发布时间已知、99 个月按时可用，范围 2016-03—2026-07；历年 1—2 月合并值中发现的后续修订冲突均跳过；
- 房地产销售面积、新开工和投资累计同比各有 237 个当前观测，其中 116 个月具有分钟级真实发布时间、114 个月按时可用，严格证据范围 2016-02—2026-07；三项各新增 62 个历史版本且 0 冲突，重复执行各为 0 新增；
- 房地产序列中，2018-12 在 2019-01-21 发布、2022-09 在 2022-10-24 发布，均晚于各自固定决策时点。这两个月按真实历史保留为“发布时间已知但当时尚不可用”，不为提高覆盖率而人工前移；
- 固定 `end=2026-07` 的 120 个月回放所需 23 个代码共有 4,768 个最终观测，其中 1,772 个具有可还原发布时间、1,763 个在固定时点前可用，15/23 个代码已有严格历史；仍有 351 个观察项因数值或公式修订的公开时点不可还原而隔离。

这里的“按时可用”按各观察月对应的固定决策时点逐项统计，不代表最新观察月已经进入回放。本轮为保持可比性把结束月明确固定在 2026-07，区间为 2016-08—2026-07；房地产历史扩容增加了可还原输入，但阶段可比月仍为 93、正式决策可比月仍为 25，路径与稳定性指标没有变化。新增证据已让“房地产与财政”块从 2018-04 起可严格评分，三条房地产信号合计覆盖恰好 65%；不过该块属于领先角色，严格领先共同篮子最高仍只有 50%，没有跨过 65% 门槛。正式决策的直接瓶颈反而在同步篮子：`CN_EXPORTS` 严格发布时间仍为 0，使“就业与外需”长期只有两项就业 PMI、覆盖 60%；社零和工业增加值没有 1 月单月值，又会影响六个月共同窗口。D9 下一步 P0 因此是补 `CN_EXPORTS` 官方首次发布时间，并做固定同步最小篮子与结构性 1 月缺口敏感性，不虚构 1 月值；P1 再补信用块或 70 城价格扩散、财政脉冲、消费者预期，使严格领先覆盖跨过 65%。

归档安全门只接受 `stats.gov.cn`、`pbc.gov.cn`、`mof.gov.cn` 的 HTTPS 官方页面和真实分钟级时间，并要求与当前值在六位小数精度下完全一致。状态通常必须是 `published`；唯一白名单派生例外是公式版本为 `pboc_ytd_diff_v1` 的人民银行累计差分。归档模式缺少专用帧时直接跳过，不会回退普通抓取器或把镜像最终值伪装为历史证据。

人民银行解析已支持直接月度社融及人民币贷款、企业债、政府债分项，并优先于累计差分；负融资和亿元/万亿元统一换算为亿元。旧新闻归档的分页、月度社融标题筛选、页面 `span#shijian` 原始时间、HTTPS 官方链接限制、坏页缓存拦截和跨批次边界补取已经实现，可定位 2013—2024 的月度首次发布，但全区间预检与数据库回填尚未完成。

现代月度社融发布正文多给出年内累计值，而不是可直接入库的单月值。正文没有直接月度值时，采集器用本期与相邻上期首次发布的同口径累计值差分，标记 `pboc_ytd_diff_v1`，并自动向更旧目录补取一篇相邻发布，避免分批边界丢月。2024-03—2025-08 首轮只读预检中，社融总量、人民币贷款、企业债月度值分别只有 1、1、5 期与数据库亿元精确值完全一致；大量新闻稿只按 0.01 万亿元披露，无法证明其与后来精确表之间没有修订，因此全部拒绝且尚未写库。当前元数据补录只保存本期来源 URL 与公式版本；若未来要导入与当前值不同的首次发布版本，必须先实现可保存前后两篇来源与修订顺序的专用版本导入器。信用脉冲另依赖名义 GDP，必须在全部依赖都有真实发布时间后以 `max(input.available_at)` 生成，当前不得直接继承社融发布时间。

## 已知历史缺口

- 规上工业增加值同比：国家统计局发布页保留近期官方观测，东方财富传输镜像补至 2008-02；重叠期始终采用官方值。镜像“发布时间”实际为观察月份，故不写入 `release_date` 或 `available_at`；统计制度下 1 月无单月值，1—2 月合并值记在 2 月，不插值补齐 1 月。
- 社融总量、人民币贷款和企业债月度增量：2015-01—2026-08。
- 社融存量同比：连续覆盖 2017-01—2019-12、2022-01—2026-08；2020—2021 的官方静态表暂未可靠定位，保持缺失。
- 社融口径人民币贷款存量同比：外沿区间同上，但另缺 2025-11、2025-12、2026-01、2026-02；没有可靠官方值的月份保持缺失。
- 地方专项债：数据库当前覆盖 2019-07—2026-07。
- 工业企业产成品存货周转天数：当前可稳定解析 2025-06—2026-07；不使用第三方估算补早期值。
